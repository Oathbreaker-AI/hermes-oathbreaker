Oathbreaker AI is now a model provider.

1. If you skipped the key prompt, add `OATHBREAKER_API_KEY` to your Hermes `.env` (create a key at https://oathbreaker.ai/dashboard).
2. Run `hermes model` and choose **Oathbreaker AI**, then a model: `oathbreaker-glm-5.3` (the flagship), `oathbreaker-glm-5.3-flash`, `oathbreaker-deepseek-v4.1-flash`, `oathbreaker-deepseek-v4.1-flash-fast` or `oathbreaker-kimi-k3.1-pro`.
